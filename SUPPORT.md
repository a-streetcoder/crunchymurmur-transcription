# Support

Use [GitHub Discussions](https://github.com/a-streetcoder/crunchymurmur-transcription/discussions)
for integration questions and
[GitHub Issues](https://github.com/a-streetcoder/crunchymurmur-transcription/issues)
for reproducible defects and feature proposals.

Include the host framework, operating system, architecture, selected engine,
model, audio format and stable error code. Never include API keys or private
recordings.
