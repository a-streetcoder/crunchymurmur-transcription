# Contributor Covenant Code of Conduct

We pledge to make participation in this project a harassment-free experience
for everyone, regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity and expression, experience, education,
socio-economic status, nationality, appearance, race, caste, colour, religion,
or sexual identity and orientation.

Examples of positive behaviour include empathy, constructive feedback,
respectful disagreement and accepting responsibility. Harassment, personal
attacks, discriminatory language and publishing another person's private
information are unacceptable.

Project maintainers may remove or reject contributions and participation that
violate these standards. Report conduct concerns privately through the
repository owner's GitHub profile.

This policy is adapted from Contributor Covenant 2.1.
